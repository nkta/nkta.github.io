- **Claude Opus 5** (Anthropic, 24/07) : nouveau flagship proche de l'intelligence frontière de Fable 5 à environ moitié prix — un vrai repositionnement tarifaire.

## 2. Frameworks & outils IA

**Écosystème MCP** — le fait marquant du mois :
- **Spécification MCP 2026-07-28** : passage en *stateless* (suppression du handshake `initialize` et des sessions), endpoint **`server/discover`**, abonnements remplacés par `subscriptions/listen`, tasks expérimentales déplacées vers l'extension `io.modelcontextprotocol/tasks`.
- **Serveurs de référence 2026.8.18** : nouveau package `@modelcontextprotocol/server-everything`, mises à jour de filesystem, time, fetch, git.

**Frameworks agents :**
- **OpenAI Agents SDK v0.19.0** (27/07) : `ProgrammaticToolCallingTool` — le modèle génère et exécute du code Python pour produire des appels d'outils.
- **LangChain « Open SWE »** (08/08) : agent de code asynchrone open source, alternative ouverte à Devin.
- **CrewAI 1.15.4** (17/07) : le Skills Repository devient stable.

**Outils de dev & inférence :**
- **Transformers v5.14.0** (15/07) : support du modèle **Inkling** (975 Md params / 41 Md actifs).
- **vLLM v0.26.0** (27/07) : support complet de la famille Inkling (CUDA graphs, décodage spéculatif MTP).
- **Ollama v0.32.12** (14/08) : Qwen 3.8 27B + lancement de **DeepSeek Harness** (agents open source) et **Muse Code** (Meta).

**Fine-tuning :**
- **TRL v1.9.0** (21/07) : datasets streaming dans GRPO/RLOO ; v1.10.0 (13/08) stabilise DistillationTrainer.
- **Axolotl v0.18.0** (17/07) : LoRA/QLoRA 4-bit *par expert* pour MoE creux (NVFP4, MXFP4, bnb).
- **Unsloth** (20/07 → 19/08) : support GPU AMD, **Unsloth Desktop**, GGUFs dynamiques 3.0.

**IDE IA :** OpenAI Codex 0.148.0 (18/08) : export TUI en Markdown, fork de sessions (`codex exec fork`).

Autres sorties notables : Google ADK v2.5/v2.7, LangSmith SDK v0.11.0, Langfuse v4.15.0, Weaviate v1.39.0-rc (Namespaces), Milvus Go SDK v3 beta, JAX v0.11.0, llama.cpp v0.1.2 (versioning sémantique), LiteLLM v1.97.0.

- **« AI Omnibus » en vigueur** (27/07) : simplification du règlement, délais étendus, garde-fous conservés.
- **Appel à 7 « AI Gigafactories » européennes** (30/07) : jusqu'à 10 Md€ publics + ~20 Md€ privés, en complément des 19 AI Factories.
- **ICML 2026 à Séoul** : Outstanding Paper « The Flexibility Trap » (diffusion LMs), Test of Time « Asynchronous Methods for DRL » (A3C).
- **Gemini dépasse 1 milliard d'utilisateurs** (11/08) : 63 % via la voix, ~150 M images/jour.
- **OpenAI lance un modèle cyber + programme Daybreak** (10/08), face à la multiplication des attaques menées par IA.
- **Nvidia s'allie à Safe Superintelligence** (27/07) : partenariat long terme de calcul avec l'équipe d'Ilya Sutskever.
- **Cursor lance un hébergement rival de GitHub** (18/08) — Cursor capitalise sur la frustration envers GitHub.
- **Le Texas suspend les nouveaux data centers** (04/08) : le gouverneur réclame des audits — le sujet énergie/IA monte.

## Analyse critique

- ✅ **Impactant** — à adopter rapidement
  - **MCP stateless** : simplification majeure du protocole, à suivre de près dans nos intégrations.
  - **Claude Opus 5** : rapport prix/perf qui change la donne pour les agents de code.
  - **Qwen 3.8** : l'open source rattrape la frontière — pertinent pour du self-hosted.
  - **EU AI Act exécuté** : obligations de transparence = checklist à intégrer dans les projets IA.
- ⚪ **Anecdotique** — pas d'urgence
  - Rythme effréné des releases (Grok 4.5 → 4.6 en 1 mois, Gemini 3.6 → 3.7 en 3 semaines) : surtout du marketing.
  - Baisses de prix GPT-5.6 : attendu, la guerre des prix continue.
- 👀 **À surveiller**
  - **Muse Glimmer** : Meta renoue-t-il durablement avec l'open source ?
  - **DeepSeek-V4-Pro GA + tarif heures creuses −50 %** : le pricing innovant continue.
  - **Cursor vs GitHub** : le paysage de l'hébergement de code bouge.
  - **Data centers / énergie** : suspension texane, gigafactories UE — le nerf de la guerre.
