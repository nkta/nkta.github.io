## 1. ☕ JDK : la fin des Mac Intel, la roadmap se précise

### 🔥 JEP 541 — Déprécier le port macOS/x64 en vue de sa suppression

Proposé en août, le JEP 541 acte une réalité : Apple a basculé tout son hardware en **AArch64** et abandonne progressivement x64. Les ingénieurs Oracle cessent donc **d'entretenir le port macOS/x64 à partir du JDK 27**. L'intention est de le **retirer définitivement** dans une version future (la dépédition est visée pour le JDK 28).

**Pour qui ?** Les développeurs qui tournent encore sur un Mac Intel doivent prévoir la migration matérielle ou passer par un environnement arm64 (CI, conteneurs). C'est une bascule de maintenance, pas une question de fonctionnalité — le runtime continue de tourner, mais plus de correctifs de sécurité ciblés pour cette architecture.

Sources : [JEP 541](https://openjdk.org/jeps/541) · [InfoWorld](https://www.infoworld.com/article/4205791/java-28-starts-to-take-shape.html)

### Roadmap Java SE — mise à jour du 4 août 2026

| Version | Type | GA | Support Premier | Fin support |
|---------|------|-----|-----------------|-------------|
| **21** | LTS | Sept. 2023 | — | Passages en licence OTN après sept. 2026 |
| **25** | LTS | Sept. 2025 | Sept. 2030 | Sept. 2033 |
| **26** | non-LTS | Mars 2026 | Sept. 2026 | — |
| **27** | non-LTS | **Sept. 2026** | Mars 2027 | — |

👉 **Point d'attention majeur :** les mises à jour de **JDK 21 LTS publiées après septembre 2026** passent sous la licence **Java SE OTN**. Si vous voulez rester sous licence permissive, il faut monter sur **JDK 25 ou plus**. C'est une échéance à anticiper dans les roadmaps d'entreprise.

Source : [Oracle Java SE Support Roadmap](https://www.oracle.com/java/technologies/java-se-support-roadmap.html)

### JDK 26 — Retour sur les 10 JEPs (GA mars 2026)

Pour rappel, JDK 26 (non-LTS, 6 mois de support Premier) a livré 10 JEPs dont : patterns sur types primitifs (`instanceof` / `switch`, 4e preview), Vector API (incubating), structured concurrency, lazy constants, AOT object caching, client HTTP/3, réduction de synchronisation dans G1, et la classe `PEM` avec un `decode()` qui renvoie le contenu Base64 décodé.

**JDK 27** devrait sortir ce mois-ci (feature freeze déjà passé en juin) et **JDK 28** est déjà en développement (JEP 534 *Compact Object Headers by Default* est passé en Candidate).

## 3. 📚 Outils, bibliothèques et pratiques

### Spring AI 2.0 — structured output auto-correctif (2.0.1 en août)

La fonctionnalité phare de la 2.0 : le LLM répond en JSON, Spring AI valide contre un schéma, et **corrige et relance automatiquement** si le format est invalide.

```java
// Spring AI 2.0 — Structured Output auto-correctif
@RestController
class AiController {
    private final ChatClient chatClient;

    @GetMapping("/recommend")
    MovieRecommendation recommend(@RequestParam String genre) {
        return chatClient.prompt()
            .user("Recommande un film de " + genre)
            .call()
            .entity(MovieRecommendation.class);
        // JSON invalide → Spring AI valide, corrige et réessaie
    }
}
```

### Quarkus Flow 1.0 — orchestrer des workflows en Java

```java
// Quarkus Flow — un workflow simple
var flow = Flows.builder()
    .withName("onboarding")
    .step("validation").service(validateCmd::apply)
    .step("notification").service(notifyCmd::apply)
    .build();

var run = flow.builder().build().run(instance, ctx);
```

### MCP (Model Context Protocol) s'installe durablement dans le monde Java

L'écosystème Java continue d'absorber MCP : les outils Spring AI peuvent être exposés comme outils MCP, et Quarkus expose ses capacités Dev UI en fonctions MCP. C'est un standard en train de devenir incontournable pour brancher vos services sur les agents IA.

## 5. 🔮 Analyse et perspectives

### ✅ Impactant — À adopter rapidement

1. **Migrer hors des Spring Boot 3.x** : les branches 3.x sont hors support OSS depuis juin, et 4.0 perd le sien en décembre. Ciblez **4.1** (stable, Java 25 compatible, virtual threads par défaut).
2. **Anticiper la fin du JDK 21 en licence permissive** : les builds 21 post-septembre 2026 passent en OTN. Montez sur **JDK 25 LTS** si vous étiez resté sur 21.
3. **Quarkus 3.40 LTS** : si vous êtes sur Quarkus, la LTS est un point d'ancrage sain, et **Flow 1.0** règle un besoin d'orchestration souvent couvert par du code maison.

### ⚪ Anecdotique — Pas d'urgence

- Quarkus 3.29 (packaging Maven, nouveaux drivers) : incrémental
- Micronaut 5.1.1/5.1.2 : maintenance classique
- Hibernate 7.4.6 : simple correctif

### 👀 À surveiller

- **JEP 541 (macOS/x64)** : si vous ciblez encore des Mac Intel en CI/dev, prévoyez la bascule — les ports arm64 deviennent l'unique voie entretenue.
- **Jakarta EE 12** : reporté à la fin 2026 (ressources limitées après le retard de l'EE 11). Core Profile attendu en Q4, Web/Platform en Q1/Q2 2027.
- **Java + IA** : Spring AI 2.0, Quarkus Flow et MCP convergent — les agents deviennent un vrai sujet d'architecture, pas un gadget. À regarder de près pour un Lead Dev.
